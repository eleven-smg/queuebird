# Code of conduct

## Expected

- Be direct, patient and respectful. Critique the work, not the person.
- Assume good faith. Ask before rewriting someone else’s contribution.
- Keep issues and PRs on topic. Move general chat elsewhere.
- Respect privacy: no personal data, private posts, cookies, tokens or account
  details in an issue, PR, screenshot or log.

## Not accepted

- Harassment, threats, discrimination or sexual attention.
- Publishing someone’s private information.
- Using the project to spam, mass-follow, mass-like, scrape personal data,
  evade platform enforcement or run accounts without a human decision.
- Credential collection or “sign in here” requests in any project space.

## Scope

This applies to issues, pull requests, discussions, commit messages and any space
where someone represents the project.

## Enforcement

The maintainer may edit or remove content, close a contribution, or block an
account. Report a problem to the maintainer through GitHub; do not argue it out
in the thread. Reports are handled privately.

This is a small project. The rule is simple: make it safe and useful for the next
person.
